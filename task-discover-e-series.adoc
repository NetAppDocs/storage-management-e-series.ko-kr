= E-시리즈 시스템을 알아보세요
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Console 에 E-Series 시스템을 추가하면 콘솔에서 E-Series 시스템을 관리하고 하이브리드 멀티클라우드 환경 전반의 데이터 인프라를 완벽하게 파악할 수 있습니다.

.필수 NetApp Console 역할
조직 관리자, 폴더 또는 프로젝트 관리자, 저장소 관리자 또는 시스템 상태 전문가. link:https://docs.netapp.com/us-en/bluexp-setup-admin/reference-iam-predefined-roles.html["NetApp Console 액세스 역할에 대해 알아보세요."^]

.시작하기 전에
다음이 필요합니다.

* E-Series 시스템에 네트워크로 연결되어 클라우드 공급자나 사내에 설치된 NetApp Console 에이전트입니다. 콘솔 에이전트를 설치하려면 조직 관리자 역할이 있어야 합니다.  귀하의 조직에 콘솔 에이전트가 있는지 확실하지 않거나 에이전트를 만들어야 하는 경우 콘솔 관리자에게 문의하세요. https://review.docs.netapp.com/us-en/bluexp-setup-admin/task-user-settings.html#contact-your-organization-administrator["귀하의 조직 관리자에게 문의하세요."^]
* 스토리지 시스템 컨트롤러의 도메인 이름 또는 IP 주소입니다.
* E-Series 시스템의 관리자 자격 증명입니다.


.단계
. 탐색 메뉴에서 *저장소 > 관리*를 선택합니다.
. *시스템* 페이지에서 *추가*를 선택하고 *온프레미스*를 선택합니다.
. *E-Series* 옆에서 *Discover*를 선택하세요.
. _E-시리즈 클러스터 세부 정보_ 페이지에서 스토리지 시스템 컨트롤러의 도메인 이름 또는 IP 주소, 시스템의 관리자 자격 증명을 입력한 다음 *추가*를 선택합니다.
